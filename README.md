# 生日电子情书

一个使用原生 HTML、CSS 和少量 JavaScript 制作的单页生日情书原型。

## 本地预览

最简单的方式是直接双击 `index.html`。也可以在项目目录中启动任意静态文件服务器，例如：

```powershell
npx --yes serve .
```

然后打开命令行显示的本地地址。

## 保存 PDF

点击页面底部的“保存这封信”，在系统打印窗口中选择“另存为 PDF”。为了保留纸张色彩，请在打印选项中开启“背景图形”。
